Turning Point Security Checklist

Yuxuan · AIML 515 · October 4, 2026

Checked means the measure is in the running local application. The last three items are limits that were reviewed and left in place on purpose.

Secrets

  • Checked. No API keys, passwords, tokens, or private keys are stored in the repository.
  • Checked. .env files are gitignored. frontend/.env.example contains only http://127.0.0.1:8000.
  • Checked. The chart library is called with online=False. City coordinates come from a local list, not a geocoding service.
  • Checked. The page refuses an API address whose host is not localhost, 127.0.0.1, or ::1, so birth details are not sent to another computer by a bad setting.

SQL injection

  • Checked. Profiles and life events are inserted and read with SQLAlchemy. User text is a bound value, not part of the SQL string.
  • Checked. The only direct SQL statement is PRAGMA foreign_keys=ON, which contains no user input.
  • Checked. A description containing DROP TABLE is stored as text, and the profile table is still there afterward.
  • Checked. A failed save rolls back the transaction, so a half-written profile is not left behind.

Personal data

  • Checked. backend/turning_point.db is gitignored and set to mode 600 when the API opens it. Other accounts on this Mac cannot read the file.
  • Checked. Chat text is limited to 1,000 characters. Birth fields, event dates, and descriptions are length-checked again before they are saved. The error does not repeat the text.
  • Checked. Validation errors omit the submitted input, so a rejected life-event sentence is not copied into the error body.
  • Checked. Unexpected server errors return a generic JSON message and do not include the exception text.
  • Checked. API responses send Cache-Control: no-store, Pragma: no-cache, X-Content-Type-Options: nosniff, and Referrer-Policy: no-referrer.
  • Checked. Session ids are random UUID values and are sent in the request body, not in the URL.
  • Checked. CORS allows only http://127.0.0.1:5173 and http://localhost:5173, and only GET, POST, and OPTIONS.
  • Checked. The reading is rendered as text in React. The page does not assign user text to innerHTML.
  • Checked. The API process used for this project listens on 127.0.0.1, not on every network interface.

Reviewed and not changed

  • There is no login. GET /users/1 returns that profile to any program that can already call 127.0.0.1:8000.
  • Profile ids are sequential. The SQLite file stores birth details and life events in plaintext.
  • Traffic is HTTP because both processes are on this computer. Do not publish port 8000.
